# BUG-001: Booking page gets stuck on infinite loading spinner

**Reporter:** [Your Name]
**Date:** [Today's Date]
**Severity:** High
**Priority:** High

## Environment
- **URL:** https://automationintesting.online
- **Browser:** Google Chrome
- **OS:** Windows (or whatever OS you are using)

## Preconditions
- The user is on the public front page.
- The user has selected valid future dates (e.g., Check-in: 2026-11-05, Check-out: 2026-11-07).

## Steps to Reproduce
1. Go to the front page.
2. Select a future Check-in date and a later Check-out date.
3. Click "Check Availability".
4. Select any available room and click "Book Now".
5. Wait for the reservation form to load.

## Expected Result
The reservation form should load, allowing the user to enter their personal details (Name, Email, Phone) to complete the booking.

## Actual Result
The page remains completely blank with a loading spinner in the center. It never loads the form, making it impossible to complete the booking.
