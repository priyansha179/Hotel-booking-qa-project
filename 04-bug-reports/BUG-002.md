# BUG-002: Contact form shows success but message does not appear in Admin inbox

**Reporter:** [Your Name]
**Date:** [Today's Date]
**Severity:** High
**Priority:** High

## Environment
- **URL:** https://automationintesting.online
- **Browser:** Google Chrome
- **OS:** Windows

## Preconditions
- The user is on the public front page.

## Steps to Reproduce
1. Scroll down to the "Send Us a Message" contact form.
2. Fill in all fields with valid data (Name: Test User, Email: test@test.com, Phone: 01234567890, Subject: Testing, Message: This is a valid test message...).
3. Click the "Submit" button.
4. Observe the success message: "Thanks for getting in touch Test user!"
5. Log in to the Admin Dashboard (admin / password).
6. Click on the "Messages" tab.

## Expected Result
The new message from "Test User" with the subject "Testing" should appear at the top of the Admin Messages list.

## Actual Result
The message is not saved. The Admin inbox still only shows the old message from "James Dean". The user is falsely told their message was sent.
